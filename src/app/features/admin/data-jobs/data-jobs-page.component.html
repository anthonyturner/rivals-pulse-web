Data jobs

Run the background data work now instead of waiting for its next scheduled run. Nothing here adds a new data source. Each run is written to an audit log, and a job cannot be started again for a short while.

Player uploads cannot be forced. They arrive when a player's PC sends a finished match, so there is nothing to run for them.

A run shows on the site after the web cache lets go of it. A new answer can take up to 5 minutes to appear, and for up to an hour after that a visitor may still be handed the older copy once while the new one loads. A page that is already open needs a reload. The home news skips the cache, so a reload shows it at once. Pulse Atlas files change when it publishes, scheduled every six hours but often later, because GitHub starts it when it can (or when you run it by hand below), and it reads the same cached answers.
